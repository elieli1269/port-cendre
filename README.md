# Port-Cendre

Jeu web original : quartier de nuit, berline, à pied, armes. Jouable dans le navigateur, y compris sur téléphone.

Ce n’est pas GTA, et ce dépôt ne contient pas d’APK Android.

## Jouer en local

```bash
npm install
npm run dev
```

Puis ouvre l’adresse affichée par le serveur.

## Commandes

- Au volant : stick gauche, ou W accélérer, S freiner, A gauche, D droite. Boutons Gaz et Frein sur téléphone.
- Sortir (F ou le bouton) : glisser l’écran pour viser, Tir en bas à droite.
- Monter pour reprendre la voiture.

Fiction originale. Épargne les civils.
